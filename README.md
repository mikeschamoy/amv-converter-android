# ClipAMV v0.3
**Your Media, Player-Ready**

Gen-2-focused AMV converter with:
- Matrix/Termux-style ClipAMV UI
- YouTube / Movie / Cartoon / Portrait modes
- Space Saver / Standard / Quality
- 15 / 25 / 30 / Auto FPS
- 216 / 208 / 200 / 192 / 184 framing
- 4:3 Full / Preserve
- Portrait Fit / Zoom / Rotate 90
- Image input -> player-ready JPEG
- Live preview + exact FFmpeg proxy refresh
- MKV / AVI / HEVC preview fallback
- Black-bar detection
- Trim start/end + preview seeks to start
- 30-second test mode
- Input/output storage estimate
- Smart <=16-character names
- Multi-file queue + one output folder
- Per-file inspect and auto crop in queue
- Background conversion + wake lock
- Notification progress, speed, ETA
- Output verification
- Recent history
- Advanced panel + diagnostics export
- FFmpeg engine self-test
- No activation system yet
- Gen 2 only; no player-profile abstraction yet

Quality modes:
- Space Saver: 15 fps default, q5
- Standard: proven defaults
- Quality: q1/qmin1
