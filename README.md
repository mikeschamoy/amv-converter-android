# AMV Converter Android v0.2

Native Android AMV converter for the calibrated 320×240 player.

## v0.2 additions

- Dark, readable button UI
- Live 320×240 player preview
- Player View vs Raw AMV
- 216 / 208 / 200 / 192 / 184 overrides
- 4:3 Full / Preserve modes
- Native preview fallback to extracted FFmpeg frame
- Black-bar / pillarbox detection
- Trim start / end
- 30-second test clip
- Rough output-size estimate
- In-app progress
- Speed + ETA
- Notification progress
- Cancel in app and notification
- Partial wake lock so screen-off conversion remains active
- Recent conversion history
- Completion notification
- Optional-audio mapping for silent host files
- Output handled by Android document picker so name conflicts are visible

## Next milestone

Batch queue / multi-file season conversion with output-folder selection.
